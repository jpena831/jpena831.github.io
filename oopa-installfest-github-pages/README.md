# OOPA Installfest

GitHub Pages version of the Workflow Wizard walkthrough.

## GitHub Pages

Upload the contents of this folder to the root of:

`jpena831/oopa-installfest`

Then configure GitHub Pages to deploy from the repository's main branch and root (`/`).

The site should be available at:

`https://jpena831.github.io/oopa-installfest/`

The walkthrough's query-string step navigation is preserved, so URLs such as:

`https://jpena831.github.io/oopa-installfest/?step=welcome`

will work.
